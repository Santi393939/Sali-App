# Salli

Salli (صلِّ) is a phone app for logging salawat on the Prophet ﷺ, alone or with a group. It is built with Expo (React Native and TypeScript) so one codebase runs on iPhone, Android and the web.

## Run it

```bash
npm install
npm run web        # preview in a browser
npm start          # open on a phone with Expo
```

## Where things live

- `src/theme`: colours, fonts, sizes (the design tokens)
- `src/components`: Card, PrimaryButton, ZelligeBand, PlasterPattern, HorseshoeArch, EightPointStar, plus Logo, Lantern (placeholder) and ProgressStar
- `src/app`: screens (Expo Router)
- `docs/screenshots`: previews from each build step
